# daofa-material-answer

初中《道德与法治》（道法 / 政治）**材料分析题答题技能**，加一套覆盖七上到九下六册课本的知识库。

给 AI 编码助手（ZCode / Claude Code 等支持 `SKILL.md` 的工具）用的技能包：贴一段材料和一个设问，它会先判题型，再从知识库里挑出这道题真正需要的那几条原理，按"总—分—总、知+材+作用句"的范式写出学生可以直接抄写的答案。

## 答题范式

从一份真实的"知能答案"（老师给的标准答案）里提炼出来的：

- **每条得分点 = 教材原理句（知）+ 材料事实（材）+ 作用句**。缺一件就丢一档分：只背原理不引材料，拿不到"结合材料"的分；只抄材料不写原理，没有教材观点；没有作用句，要点不完整。
- **整题走"总—分—总"**：总起句点题干关键词 → 分点逐条（每点一理一材一作用）→ 结尾升华（应然做法 + 预期作用）。
- **题型由题干设问决定结构**：体现说明类、观点评析类、认识类（是什么→为什么→怎么做）、原因因素类（多维互斥切分）、关系类、做法类、开放类。
- **选知识点三条约束**：题干定向（问哪个模块就只在该模块里挑）、一材一理（每条原理都要能在材料里找到对应动作）、互斥不重复（分点必须处在不同维度）。

输出分三段：题型判定 / 采分点映射表（材料动作 ↔ 教材原理 ↔ 作用句）/ 可直接抄写的答案。

```
  knowledge-8a-unit1..4.md   八上（走进社会生活 / 维护社会秩序 / 勇担社会责任 / 维护国家利益）
  knowledge-8b-unit1..5.md   八下 · 宪法专册（坚持宪法至上 / 理解权利义务 / 认识国家制度 / 走近国家机构 / 建设法治中国）
  knowledge-9a-unit1..4.md   九上（坚持党的全面领导 / 进入新时代 / 奋进新征程 / 共圆中国梦）
  knowledge-9b-unit1..3.md   九下（我们共同的世界 / 世界舞台上的中国 / 走向未来的少年）
scripts/
  textbook-tools.py          从课本 PDF 造知识库原料：toc / text / render
```

`答题逻辑.md` 和 `SKILL.md` 分工不同：前者讲**为什么**（分数怎么给、三件套各自的门道、八种题型的骨架、选知识点的三条约束、术语替换表、常见失分对照），后者讲**怎么操作**（流程和输出格式）。想弄明白依据、或者要给别人讲评，看前者；直接答题，看后者。

知识库共 24 份、约 3200 条**带课本页码的原理句**（`（P##）` 是书上印刷页码）。每份文件里除了原理句，还有"材料信号"（什么情境该想到这条）和"配套作用句"，以及每组知识"回答什么问题、能在什么题里当知用"的落点说明。

内容筛选按一条判据：**这句话单独拿出来能不能当答案里的"知"用**。课本正文的观点句、结论句、加粗句，以及 `相关链接`、`阅读感悟`、`方法与技能`、`启思导行`、`探究与分享`里的观点句都收；`生活观察`和探究与分享的设问、活动任务、填表、图注、活动步骤不收。

## 用法

把仓库克隆（或复制）到技能的发现目录：

```bash
git clone https://github.com/justAWingTip/daofa-material-answer.git \
  ~/.zcode/skills/daofa-material-answer
```

ZCode 的用户级技能目录是 `~/.zcode/skills/<name>/`（跨工具的通用位置是 `~/.agents/skills/<name>/`）。放进去后重启客户端或开新会话，技能列表里就会出现；也可以 `/daofa-material-answer` 直接调用。

然后正常提问即可，例如：

> 阅读材料，回答问题。【四代人的生活】……结合材料，说明中国共产党在不同历史时期取得的伟大成就，并分析这些成就与小明一家命运变化的关系。（12分）

## 扩充新册次

`scripts/textbook-tools.py` 是造知识库原料的工具：

```bash
python scripts/textbook-tools.py toc    <课本.pdf>              # 看目录结构与单元划分
python scripts/textbook-tools.py text   <课本.pdf> <输出目录>    # 抽文字层，标注页脚印刷页码，报告广告插页导致的页码跳变
python scripts/textbook-tools.py render <课本.pdf> <输出目录>    # 逐页导 PNG，用于核对栏目归属
```

依赖 PyMuPDF（`pip install pymupdf`）。要点：文字层用来取准原句，页面图用来定栏目归属（文字层常把栏目名和内容的顺序打乱）；每页标题形如 `===== PDF页 N | 印刷页 M =====`，M 取自页脚；这套课本每册都夹了一页广告插页，所以"PDF 页 = 印刷页 + k"的 k 会中途变化，脚本会自动指出来。
